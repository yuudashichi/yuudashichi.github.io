Dijkstra算法

求一个指定起点到其他所有顶点的最短路径，即单源最短路径，适用于非负有权图；

基本思想：从起点开始，依次寻找距离起点最近的节点，并更新其相邻节点的距离和路径；

Dijkstra算法属于贪心

算法流程：

  1. 每次选择距离起点最短的节点，将其标记为已处理过
  2. 从这个节点更新能到的节点的最短路径，将边加入队列中
  3. 已处理过的节点的距离不会再改变（如果是负权图，之后可能会出现更短的路径，这里就会出错）

Bellman-Ford算法

单源最短路径算法

特点是：支持负权边；可以检测负权环

算法流程：

  1. 起点距离设置为 0，其他顶点设置为无穷大
  2. 对所有边执行 V - 1 轮松弛
  3. 如果某一轮没有更新，可以提前结束再遍历一遍所有边
  4. 如果仍然可以松弛，说明存在负权环

Floyd算法

求图中任意两个顶点之间的最短路径，即多源最短路径；

基本思想：通过逐个考虑每一个节点作为中间节点，更新所有节点之间的最短路径；

Floyd算法属于动态规划；

时间复杂度O(n^3)，适合节点少的稠密图

A*算法

A*（A-Star）是一种常用的最短路径搜索算法，可以理解为：Dijkstra 算法 + 启发式函数

启发式函数影响的是取下一个节点的优先顺序，核心公式是：

f(n)=g(n)+h(n)

  • f(n)：经过当前节点到达终点的预计总代价
  • g(n)：起点到当前节点的实际代价
  • h(n)：当前节点到终点的预估代价

计算两点代价(距离)常用的计算方式：

名称 公式
曼哈顿距离 d = abs(x1-x2)+abs(y1-y2)
欧氏距离 d = sqrt( (x1-x2)^2 + (y1-y2)^2 )
切比雪夫距离 d = max(abs(x1 - x2), abs(y1 - y2))

最小生成树

最小生成树是所有节点的最小连通子图，即以最小的成本（边的权值）将图中所有节点链接到一起；

Prim算法

选点；

Prim算法属于贪心算法

核心逻辑：

  1. 从任意一个顶点开始。
  2. 每次从“已加入的顶点”到“未加入的顶点”中，选择权值最小的边。
  3. 将新顶点加入最小生成树。
  4. 重复操作，直到所有顶点都被加入

Kruskal算法

选边

Kruskal算法属于贪心算法

核心逻辑：

  1. 将所有边按照权值从小到大排序

  2. 依次遍历排序后的边

  3. 判断这条边连接的两个顶点是否已经连通：

    • 不连通：选择这条边，并合并两个连通分量
    • 已连通：跳过，否则会形成环

    判断是否连通用到了并查集

  4. 选择到 (n-1) 条边时结束

同余

​ 定义：两个数x和y，如果(x - y) mod m = 0，则称x与y对模m同余，记作：x = y (mod m)

也就是说两个数模一个数后得到相同的数，例如 42 = 12 （mod 10）、-17 = 3 （mod 10）

​ 处理取模技巧：如果数x为负数，则 x mod m = y mod m 等同于(x mod m + m) mod m = y mod m

贪心

本质是选择每一阶段的局部最优，从而达到全局最优。

贪心算法一般分为如下四步：

  1. 将问题分解为若干个子问题
  2. 找出适合的贪心策略
  3. 求解每一个子问题的最优解
  4. 将局部最优解堆叠成全局最优解

碰到需要满足多个条件时，往往需要分开单独考虑，而不是一起考虑，会顾此失彼

背包问题

分清求的是组合数还是排序数，以及背包的容量和物品的价值是什么

01背包

每个物品只能拿一次，求能拿的最大价值

做法：因为不能重复选同一个物品，所以要从大到小遍历容器， 避免同一个物品被多次计算

  1. 定义dp[j] = 背包容量为 j 时的最大价值
  2. 遍历物品 + 容器

做法：从小到大遍历容器，让物品可以被重复选择

  2. 如果求组合数就是外层for循环遍历物品，内层for遍历背包。
  3. 如果求排列数就是外层for遍历背包，内层for循环遍历物品。

树形DP

在树结构上进行动态规划的算法，通过后序遍历（DFS），利用子节点的状态来计算父节点的状态，从而求解整棵树上的最优解

做法：

  1. 定义状态：dp[u] 或 dp[u][...] 表示以节点 u 为根的子树所对应的问题答案。
  2. 确定状态转移：根据节点 u 的所有子节点 v 的 dp[v]，计算 dp[u]。
  3. DFS 遍历：由于父节点依赖子节点，因此通常采用后序遍历进行计算。
  4. 得到答案：根节点的 DP 状态或所有节点状态的最优值即为最终答案。

  • 337. 打家劫舍 III

数位DP

用于统计某个数值区间内满足特定数位性质的数字个数的动态规划算法。它通过按位枚举数字，并记录构造过程中的状态，避免暴力枚举每个整数。

特征：

  1. 数据范围非常大(不能暴力)
  2. 和每个数位有关
  3. 有明显的数学风味
  4. 喜欢问范围[L, R]中有多少(不)符合的数
  5. 模板性很强
