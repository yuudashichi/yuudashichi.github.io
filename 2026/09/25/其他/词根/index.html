词根词缀

最常见的

前缀(12)

前缀通常决定了单词的意思

  1. **e / ex / ef**：外 、 出；export(出口)
  2. **in / im**：内 、 进；inject(注射)
  3. 前
    1. **pro**：动态向前；progress(进步)
    2. **pre**：静态在前、预先、提前；prepare(预测)
  4. **re**：回、再次；return(返回)
  5. **co / con / com / col**：聚集、一起；collect(收集)
  6. **di / dis / dif**：分散、分开；divorce(离婚)
  7. **super / over / sur**：上、超过；surrealism(超现实主义)
  8. **under / de / sub / sup**：下、不足；decrease(减少)
  9. **trans**：转移、转变；transfer(转移)
  10. **inter**：相互之间；internet(互联网)
  11. **a + 双写辅音字母**：强调；assert(断言)
  12. **un / mis / im / in / ab / dis / il**：否定前缀；abnormal(异常)

后缀(3)

后缀通常决定了单词的性质

  1. **ate / ize / ify / ish**：动词后缀
  2. **ent / ful / ous / al / ive / ible / able / ant**：形容词后缀
  3. **ion / tion / ation / ness / ity / ality / ment / ence / ance / ism**：名词后缀
